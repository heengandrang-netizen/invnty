STOCKSYNC PRO v18.4.1 — DEPLOYMENT

1. Upload the CONTENTS of this folder to the ROOT of your GitHub Pages branch/repository.
   index.html, sw.js, manifest.json, firebase-config.js and the icons must remain beside each other.
2. Firebase Authentication > Settings > Authorized domains: include your GitHub Pages domain.
3. Authentication > Sign-in method: Email/Password must be enabled.
4. IMPORTANT: deploy the included firestore.rules to the same Firebase project.
   v18.4 adds a tightly restricted permission that lets a Tally-role user create only new Item Master records that belong to their currently-processing Tally import. Without the new rules, valid unmatched rows will fail to auto-create.
5. After deploying, hard refresh once (Ctrl+Shift+R). If installed as a PWA, close/reopen it once so the v18.4 service worker activates.

v18.4 TALLY EASY IMPORT:
- Valid unmatched rows no longer block Tally upload; they are auto-created.
- Auto-created items by Tally staff are marked `Imported · review` for Master.
- Rows without quantity are ignored instead of blocking the full file.
- Exact duplicate rows with the same quantity are automatically de-duplicated.
- Conflicting duplicates, ambiguous mappings and invalid quantities show an inline Fix Issues panel with Quantity, Map to item and Skip row controls.
- Minor spelling differences with matching size/number can be smart auto-matched; numeric variants (e.g. 10g vs 20g) are never auto-matched merely because names are similar.


v18.4.1 ZERO-STOCK IMPORT:
- Tally zero stock is valid and imported.
- Keep Zero-stock mode ON to treat matched blank closing balances as zero.
- Blank unmatched rows remain ignored for safety.
- Hard refresh/reopen the PWA so the v18.4.1 cache activates.
