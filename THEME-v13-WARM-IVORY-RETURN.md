# v13 — back to light (Warm Ivory), keeping the premium structural work

The dark "Ledger" theme (v11) didn't land well. Reverted to a light theme — not by undoing v11,
but by keeping every non-color improvement from it (single consolidated stylesheet, Manrope font,
decluttered topbar/nav, refined shadows and spacing) and swapping the color tokens back to a
light palette built on the app's original Warm Ivory identity: cream canvas, **sage green as the
primary action color**, **bronze as the secondary accent** — the same two colors the app used
across v10.2-v10.7, just with the accumulated CSS conflicts from that era gone for good.
